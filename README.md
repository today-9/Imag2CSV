# Imag2CSV

グラフ画像からデータ点を抽出して CSV に変換する GUI ツール。

## 起動

```powershell
uv sync        # 初回のみ
uv run python -m imag2csv
```

> `uv run imag2csv` でも起動できますが、Windows の「スマート アプリ コントロール」が有効な環境では
> uv が生成する未署名の `imag2csv.exe` がブロックされます（os error 4551）。
> `python -m imag2csv` は署名済みの `python.exe` 経由で起動するため、この制限を受けません。

## 使い方

1. **画像を読み込む** — 「ファイルを開く」「画面キャプチャ」（ドラッグで範囲選択）、または Ctrl+V で貼り付け
2. **軸キャリブレーション** — X1/X2/Y1/Y2 のボタン → 画像上の軸の既知点をクリック → 実際の値を入力
3. **色を選ぶ** — 「色取得」モードで抽出したい線・点の色をクリック。「許容度」スライダーで類似色の範囲を調整（マスク表示で確認）
4. **（必要なら）ROIブラシ** — 「ブラシ」で検出したい範囲を塗る。凡例やグリッド線など同色ノイズを除外できる
5. **検出実行** — 分割方向（X/Y）とデータ点数を指定して実行
6. **手動調整** — 「点編集」モードで、ドラッグ / 矢印キー（Shiftで5px）/ Ctrl+クリック追加 / Del削除。ホイールでズーム、Ctrl+0 で全体表示
7. **CSVエクスポート** — 系列ごとに `<系列名>_x, <系列名>_y` 列で出力（UTF-8 BOM付き、Excel対応）

複数系列は「系列」パネルで追加し、系列ごとに色を選んで検出します。
